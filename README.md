# 🌌 CosmoDist: Explore the Expanding Universe

CosmoDist is a Streamlit-based app that lets you interactively explore the relationship between redshift, distance, and light travel time based on real cosmological physics.

---

## 🚀 Features

- Input redshift (z) and calculate:
  - Recession velocity (relativistic Doppler)
  - Distance using Hubble's Law
  - Light travel time from the object to Earth
- Visualize:
  - Redshift vs Light Travel Time
  - Redshift vs Distance

---

## 🔧 Tech Stack

- Python
- Streamlit
- Astropy
- Matplotlib / NumPy.

---

## 📦 Setup Instructions

1. Clone the repo:
   ```bash
   git clone https://github.com/yourusername/CosmoDist.git
   cd CosmoDist
   ```
2. Create a virtual environment and activate it
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the app:
   ```bash
   streamlit run streamlit_app.py
   ```
